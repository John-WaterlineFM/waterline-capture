ISO 7010 safety signs, as Wikimedia Commons publishes them (DEC-0342). Kept unaltered.
Checked 23 Oct 2026: each file is byte for byte the file Commons served that day (SHA-1 below), and none holds a script.
Commons tags them public domain on a "no originality" claim; that is not a grant from ISO, whose position is that
reproduction needs its permission. If ISO or NSAI objects, these files are swapped for a licensed set and no code changes.
The signs keep their own colours in every theme: they are fixed by S.I. 299 of 2007, Schedule 9 (DEC-0342 rule 2).
